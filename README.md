# OmahaLatam Theme (jhontra-theme)

WordPress theme for [omahalatam.com](https://omahalatam.com) — Jhontra PLO5 Poker, the #1 Omaha authority in Latin America.

## Structure

- `style.css` — Theme metadata
- `functions.php` — Theme setup, image sizes, Google Fonts, JSON-LD schema
- `header.php` — Age gate 18+, sticky nav, J♠ logo, mobile menu
- `footer.php` — CTA band, 4-column footer, 18+ warning, WhatsApp FAB
- `archive.php` — Blog archive with featured post + grid + sidebar
- `single.php` — Single post with progress bar, TOC sidebar, share buttons
- `blog-styles.css` — Complete blog CSS
- `home.php` / `index.php` — Template routing
- `front-page.php` / `front-page.html` — Homepage

## Deploy

Connected to Hostinger via Git auto-deploy to `wp-content/themes/jhontra-theme/`
